1. Executive Summary & Core Privacy Philosophy

Zero-knowledge, offline-first client architecture

At HelpOfAi (HOA), we hold the conviction that privacy is a fundamental human right. Unlike cloud-based media aggregators, HOA Video Player is intentionally engineered as an offline-first, standalone media workstation.

Zero Remote Server Footprint

We do NOT operate proprietary user databases, cloud storage servers, scraping proxies, or user tracking telemetry servers. Your personal video files, audio tracks, folders, and private media never transit across any HelpOfAi server.

All video parsing, thumbnail generation, hardware decoding, subtitle formatting, audio equalization, and file protection happen 100% locally on your physical device.

3. On-Device Media Processing & Diagnostics

Technical details of playback, indexing, and diagnostics

To provide ultra-fast video browsing and studio-grade playback, HOA Video Player performs all computations in sandboxed local runtime environments:

MediaStore Indexing Local Cache
Directly queries Android's native MediaStore provider for filenames, durations, resolutions, and folder paths. Stored in high-speed in-memory Room SQLite database.
Intelligent Thumbnails App-Private
Keyframes extracted on-device using MediaMetadataRetriever. Thumbnails reside solely in your app-isolated internal cache and are never uploaded.
Diagnostics & AI Engine Hardware Shaders
Scene detection, bit-depth inspection, HDR transfers, and OpenGL video enhancements run entirely on your device's GPU and CPU.
Audio Pipeline AudioFx Engine
Equalizer, Bass Boost, Virtualizer, and Reverb attach to the local media session. No microphone or voice recording capability exists in the app.

4. Zero-Knowledge Private Vault Architecture

Cryptographic specifications and user sovereignty

The Private Vault provides military-grade file confidentiality for sensitive personal videos:

  • Encryption Standard: Files moved into the Private Vault are encrypted using AES-256 in Galois/Counter Mode (GCM), ensuring both confidentiality and data authenticity.
  • Key Derivation: Your PIN derives the cryptographic master key using PBKDF2 with HMAC-SHA256 utilizing salted iterations.
  • Zero-Knowledge Assurance: The developer, HelpOfAi, does not possess or store your PIN or recovery keys. If you uninstall the app or forget your PIN, encrypted vault data cannot be recovered by any third party.
  • Memory Protection: Decryption keys reside strictly in volatile RAM during active playback and are automatically purged upon exiting the vault or locking the screen.

5. Watch Party Peer-to-Peer (P2P) LAN Streaming

Direct Wi-Fi / Hotspot media synchronization

The Watch Party feature enables synchronous media playback between multiple devices without routing through any external cloud relay:

Isolated Local Subnet Only

Media streaming occurs directly over your local Wi-Fi router, Wi-Fi Direct, or portable hotspot using an embedded point-to-point HTTP/WebSocket socket service.

  • No video data ever leaves your physical Wi-Fi network or touches external routing servers.
  • Control signaling (Play, Pause, Seek, Speed Sync) is exchanged solely between local IP addresses on your subnet.
  • Clients cannot access the host device's file system outside of the single selected video stream.

6. Third-Party Advertising (Google AdMob SDK)

Advertising governance, identifiers, and opt-out controls

To provide HOA Video Player as a free utility without subscription paywalls, this application integrates the Google Mobile Ads (AdMob) SDK.

Google AdMob operates in accordance with Google's Privacy Policy. The SDK may process certain device diagnostics and advertising identifiers:

  • Google Advertising ID (GAID / AAID): A resettable pseudonymous identifier used by advertising networks to serve personalized or contextual advertisements.
  • Network & Device Telemetry: IP address (utilized for coarse city/country location), mobile carrier, device manufacturer, screen dimensions, and operating system build.
  • Ad Performance Metrics: Viewability status, clicks, impressions, and diagnostic latency metrics.
Your Advertising Privacy Rights & Opt-Out Options

You maintain complete control over targeted advertising. You can reset or permanently delete your Advertising ID at any time:
Android Settings → Google → Ads → Reset Advertising ID or Delete Advertising ID.

For complete details regarding Google's data practices, please review the official Google Advertising Privacy Policy.

7. Android Runtime Permissions & Technical Justifications

Explicit technical rationale for every manifest permission

We adhere strictly to the principle of least privilege. Permissions are requested only when necessary to execute user-demanded features:

Permission Name Min API Purpose & Technical Necessity Scope / Restriction
READ_MEDIA_VIDEO API 33+ Index and play video files stored on internal/external storage. Read-only media scope.
READ_EXTERNAL_STORAGE API 21-32 Legacy media indexing on Android 12 and below. Read-only storage scope.
MANAGE_EXTERNAL_STORAGE API 30+ Optional. Required for advanced File Manager (move, rename, vault encryption, cut/paste). User-granted explicit consent only.
FOREGROUND_SERVICE_MEDIA_PLAYBACK API 34+ Uninterrupted background audio playback and Picture-in-Picture (PiP). Bound strictly to active playback service.
INTERNET & ACCESS_NETWORK_STATE All Delivery of Google AdMob ads and local Watch Party socket communication. No cloud telemetry transmission.
POST_NOTIFICATIONS API 33+ Display media playback controls (Play, Pause, Skip) in system shade. Media session controls only.
SYSTEM_ALERT_WINDOW All Display floating pop-up mini player over other applications. Optional user toggle.
WAKE_LOCK All Prevent screen timeout and sleep during active video playback. Released immediately on pause/exit.

8. Local Crash Reporting & Telemetry Policy

No silent background tracking or surveillance daemons

In the rare event of an unexpected application crash, HOA Video Player intercepts the exception via a custom local UncaughtExceptionHandler:

  • The diagnostic stack trace, Android SDK version, and device model are displayed on an interactive crash recovery screen on your device.
  • No Silent Uploads: Stack traces are NEVER automatically uploaded to third-party crash analytics vendors (such as Firebase Crashlytics or Sentry).
  • Manual User Transmission: You retain complete discretion. If you choose to contact our support engineers, the log is shared exclusively via your default email application.
